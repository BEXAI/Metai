## Decisions / deviations (with reasons)

1. **Log payload extensions (verifier tracks T1/T9 must mirror):**
   - `move` payload = `{turn_index, player, agent_id, submission, notation, state_hash, draws}` plus optional `forced:'illegal'` when the 3rd illegal attempt forced a seeded random legal move; `submission` is then the rejected 3rd submission while `notation` is the move actually applied (signature still covers the submission body — honest record).
   - `resign` / `draw_offer` / `draw_accept` payloads carry the full `submission` in addition to `{turn_index, player}` so their Ed25519 signatures are verifiable offline (the frozen comment shape alone can't recompute the signed message).
   - Every strike is its own `strike` entry `{turn_index, player, reason: 'illegal_move'|'timeout', strike_count}`, appended after the entry that caused it (in simultaneous phases the illegal-move strike is logged at submission time, i.e. before the forced `move` entry which only exists at resolution).
   - `timeout` payload exactly per replay.ts comment.
2. **Turn-index semantics:** one decision point per index. In a simultaneous phase ALL movers sign and log the same `turn_index`; the counter advances once when the phase resolves. Log `seq` stays unique/ordered.
3. **Simultaneous collection:** submissions are validated (signature/turn/legality with the 3-step policy per player) then HELD; applied in seat order only when every mover is in or the single shared deadline passes (missing movers get defaultMove-else-seeded-random + strike). Held moves invalidated by earlier applications get a seeded random legal substitute + strike (documented rare path). Terminal mid-resolution stops remaining movers (matches kernel playout semantics). Draw offers are rejected in simultaneous phases (`draw_offer_unavailable`).
4. **Draw offer validity:** offer registers when the offerer's own (unforced) move applies; `validAtTurn = offerTurn + 1`; acceptance = a signed submission with `draw_offer:true` from another player at exactly that turn (its move is not applied); any other consumption of that turn expires the offer. Result `{winners:[], draw:true, reason:'agreement'}`.
5. **Forced-move draw ordering:** the seeded pick (`illegal:turn:N` / `timeout:turn:N`) is always drawn immediately before its `apply`, in application order — never earlier — so an offline verifier replaying entry-by-entry reproduces the exact draw sequence.
6. **Forfeit vs terminal:** if the forced 3rd-illegal/timeout move itself ends the game, the game result stands (terminal beats forfeit); otherwise 3 strikes → `forfeit` entry + result `{winners: others, draw:false, reason:'forfeit'}` (multiplayer: all other seats win — T8 may refine rating treatment).
7. **Protocol rejections ≠ illegal moves:** bad signature / wrong turn / unknown agent / not-your-turn / oversized commentary are rejected without consuming an illegal-move attempt; recorded in `snapshot.rejections` (ring of 100, off-chain) as A9 evidence.
8. **Commitment/final seed** computed via T2's `makeCommitment`/`deriveFinalSeed`; chain entries via T2's `appendEntry`; signatures via `verifyEd25519`.
9. **Clocks:** per-move budget = `max(1, round(perMoveMs * clock_scale))`; `cumulativeMs` per seat tracked (submission receipt time; full budget charged on timeout) but no cumulative-exhaustion rule exists in the frozen policy — informational for now.
10. **Resignation** allowed from any seated player while running (turn_index in the signed body must equal the current turn to prevent replay).
11. **PLAN.md untouched** per hard rule; this file is the track note. Suggested one-liner for whoever owns PLAN.md: "T6: rooms core+DO done; log payload extensions for forced moves and signed resign/draw entries documented in notes/T6.md; verifiers must mirror."

## Seed-draw purposes used by rooms/agents
- `illegal:turn:<N>` — forced random legal move after the 3rd illegal attempt of a turn (also for held moves invalidated mid-resolution).
- `timeout:turn:<N>` — random legal move on deadline when the game has no `defaultMove` (games WITH defaultMove draw nothing on timeout).
- `random:turn:<N>` — house random agent picks (agent-local stream `sha256Hex(agentId+gameId)`, NOT the game stream).
- Game-owned purposes pass through untouched; every applied entry's `draws` field is the exact delta of `seed.draws()` for that application.
